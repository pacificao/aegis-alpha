# Future Robinhood Integration

Robinhood connectivity is a future validation milestone, not Phase 1 functionality. Use a dedicated Robinhood Agentic account, never a personal primary account. A future gateway security domain may use Robinhood Trading MCP behind a broker-neutral `BrokerAdapter`, deterministic RiskEngine authorization, explicit scopes, reconciliation, idempotency, immutable audit records, circuit breakers, and revocation procedures. Production credentials must never enter research, frontend, source control, logs, or AI-agent environments.
