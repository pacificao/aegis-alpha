# Phase 1 Completion Criteria

Complete when an authenticated browser session reaches the Aegis UI through Nginx; FastAPI persists roadmap changes in PostgreSQL and reports Redis healthy; migrations and backend/frontend/startup tests pass; only SSH/HTTP/HTTPS are externally exposed; documentation and development state are current; CI protects main where repository settings permit; builds are reproducible; and trading remains disabled. Release the verified commit as `v0.1.0-core` after review.
